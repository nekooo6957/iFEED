# 宠物养成系统设计文档

## 一、设计概述

为 iFEED 游戏添加宠物养成系统，与现有闯关模式并行，增加游戏留存和互动深度。

### 核心功能
- 双入口设计：闯关模式 + 专属动物养成
- 天选宠物机制：闯关模式最先投喂成功100次的动物
- 每日打卡+广告机制获取投喂次数
- 属性成长：强壮度 + 形态变化系统
- 排名展示：模拟数据 + 自定义称号

---

## 三、数据结构设计

### 新增类型定义 (types.ts)

```typescript
// 玩家基础数据
export interface PlayerData {
  playerId: string;           // 随机生成的唯一ID，格式 "player_xxxxx"
  selectedProvince: string;    // 选择的省份（如"广东"、"湖南"）
  chosenPet: {
    animalType: AnimalType | null;  // 天选宠物类型
    feedCount: number;             // 累计投喂次数（达到100时成为天选宠物）
    strength: number;              // 强壮度 0-1000+
    customName: string;           // 自定义名称
  } | null;
}

// 养成系统每日数据
export interface PetDailyData {
  date: string;              // 日期 "2024-03-14"
  checkedIn: boolean;         // 今日是否已打卡
  feedCount: number;          // 今日已投喂次数（打卡3次+广告）
  adCount: number;            // 今日已看广告次数（上限3次）
}

// 排名模拟数据
export interface RankingData {
  rank: number;
  petName: string;
  province: string;
  strength: number;
}
```

## 五、功能流程设计

### 5.1 天选宠物判定流程

```
闯关模式每次投喂成功后（GameScreen.tsx）:
  1. 读取 localStorage 中的 chosenPet.feedCount
  2. 对应动物类型 feedCount++
  3. 检查是否首次达到 100 次
  4. 如果达到：
     - 设置 chosenPet.animalType = 该动物
     - 设置 chosenPet.feedCount = 100
     - chosenPet.strength = 0
     - chosenPet.customName = ANIMALS[type].name
  5. 保存到 localStorage
```

### 5.2 养成交付流程

```
用户按住 svg hand 向下拖动（弹弓机制）:
  1. 检查剩余投喂次数 > 0
  2. 显示蓄力条和方向箭头（复用现有逻辑）
  3. 松手：
     - feedCount--
     - 食物朝拖动方向飞出（0.8秒动画，复用现有 FlyingFood）
     - 碰撞检测：宠物固定在中央，必定命中
  4. 强壮度 +5
  5. 显示 "+5 强壮度" 漂浮动画
  6. 检查形态升级：
     • 0 → 100: 病怏怏 → 匀称 (弹窗提示)
     • 100 → 500: 匀称 → 肌肉 (弹窗提示)
     • 500 → 1000: 肌肉 → 超级肌肉 (弹窗提示 + 解锁称号)
  7. 更新属性面板进度条
  8. 如果次数用完：禁用投喂，提示需打卡或看广告
```

### 5.3 每日打卡流程

```
进入养成系统时:
  1. 获取当前日期
  2. 对比 localStorage 中的日期
  3. 如果是新日期：
     - checkedIn = false
     - feedCount = 0
     - adCount = 0
  4. 更新打卡按钮状态

点击打卡按钮:
  1. checkedIn = true
  2. feedCount = 3
  3. 按钮变灰显示"已打卡"
  4. 保存 localStorage
```

### 5.4 广告流程

```
点击广告按钮:
  1. 检查 adCount < 3
  2. 显示广告模拟弹窗（demo 阶段用 setTimeout 模拟）
  3. 等待 3 秒（模拟广告播放）
  4. 播放完成后：
     - adCount++
     - feedCount++
     - 更新广告按钮显示 "今日剩余广告：X/3"
  5. 保存 localStorage
```

## 六、宠物形态系统

| 强壮度范围 | 形态名称 | 视觉描述 |
|-----------|----------|----------|
| 0 - 99 | 病怏怏 | 瘦弱、病怏怏的 emoji |
| 100 - 499 | 匀称 | 正常体型 |
| 500 - 999 | 肌肉 | 肌肉发达 |
| 1000+ | 超级肌肉 | 超级无敌大肌肉形态 |

### 形态变化触发
- 每次投喂后检查 strength 是否跨越阈值
- 跨越时显示弹窗："恭喜！你的宠物进化为 [形态名称]！"
- 达到 1000 时额外显示："恭喜解锁称号：[省份]最强[动物]！"
